## What is ETMDB?

ETMDB (Ethiopian Movie Database) is a free, open REST API for discovering Ethiopian cinema.
It aggregates metadata for 500+ titles from TMDB, Wikidata, Wikipedia, and YouTube.

## Base URL

```
https://api.etmdb.dev/api/v1
```

## Key Features

- **500+ titles** — movies and series in Amharic, Tigrinya, Oromo, and Somali
- **YouTube links** — 861+ video links with view counts and thumbnails
- **No auth required** — all GET endpoints are fully open
- **Discover** — filter by genre, year, rating, language, country
- **Trending** — ranked by YouTube view counts (day / week / month)
- **Search** — full-text across titles, overviews, and people

## Data Sources

| Source | What it provides |
|---|---|
| TMDB | Posters, ratings, descriptions, release dates, cast |
| Wikidata | Structured metadata, directors, IMDB cross-references |
| Wikipedia | Ethiopian film listings and context |
| YouTube | Video links, view counts, thumbnails |
