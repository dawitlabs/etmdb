## List Movies

`GET /movies`

| Parameter | Type | Default | Description |
|---|---|---|---|
| `page` | int | 1 | Page number |
| `per_page` | int | 20 | Results per page (max 100) |
| `sort_by` | string | `title` | `title`, `release_year`, `tmdb_rating` |
| `year` | int | — | Filter by exact release year |
| `language` | string | — | ISO 639-1 code (e.g. `am`, `ti`) |
| `country` | string | — | ISO 3166-1 code (e.g. `ET`) |

```bash
curl "https://api.etmdb.dawit.dev/api/v1/movies?sort_by=release_year&per_page=10"
```

## Popular Movies

`GET /movies/popular`

Returns movies ranked by total YouTube view counts.

```bash
curl https://api.etmdb.dawit.dev/api/v1/movies/popular
```

## Top Rated


## Recent

`GET /movies/recent`

```bash

```

## Movie Detail

`GET /movies/{slug}`

Returns the full movie object including genres, credits, and YouTube links.

```bash
curl https://api.etmdb.dawit.dev/api/v1/movies/difret
```

## Similar Movies

`GET /movies/{slug}/similar`

Returns movies sharing the same genres, sorted by rating.

| Parameter | Type | Default |
|---|---|---|
| `limit` | int | 12 (max 30) |

## Videos

`GET /movies/{slug}/videos`

Returns all YouTube links for a movie, primary first.
