`GET /discover`

The most powerful endpoint — filter by any combination of genre, year, rating, language, country, and type, with multiple sort options.

## Parameters

| Parameter | Type | Description |
|---|---|---|
| `type` | string | `movie`, `series`, or `all` |
| `genre` | string | Genre slug (e.g. `drama`, `comedy`) |
| `year` | int | Exact release year |
| `year_gte` | int | Release year ≥ |
| `year_lte` | int | Release year ≤ |
| `rating_gte` | float | TMDB rating ≥ (0–10) |
| `rating_lte` | float | TMDB rating ≤ (0–10) |
| `language` | string | ISO 639-1 code (e.g. `am`) |
| `country` | string | ISO 3166-1 code (e.g. `ET`) |
| `sort_by` | string | See sort options below |
| `page` | int | Page number |
| `per_page` | int | Results per page (max 100) |

## Sort Options

| Value | Description |
|---|---|
| `popularity.desc` | By YouTube views (default) |
| `rating.desc` | TMDB rating, highest first |
| `rating.asc` | TMDB rating, lowest first |
| `year.desc` | Newest first |
| `year.asc` | Oldest first |
| `title.asc` | Alphabetical |
| `title.desc` | Reverse alphabetical |

## Examples

```bash
# Drama movies from 2015–2023 with rating ≥ 7
curl "https://api.etmdb.dawit.dev/api/v1/discover?type=movie&genre=drama&year_gte=2015&year_lte=2023&rating_gte=7&sort_by=rating.desc"

# Amharic content sorted by newest
curl "https://api.etmdb.dawit.dev/api/v1/discover?language=am&sort_by=year.desc"

# Ethiopian series, most popular
curl "https://api.etmdb.dawit.dev/api/v1/discover?type=series&country=ET&sort_by=popularity.desc"
```
