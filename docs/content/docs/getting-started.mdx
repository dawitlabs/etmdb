## Quick Start

No API key required. Just call the endpoint:

```bash
curl https://api.etmdb.dev/api/v1/movies/popular
```

## Response Format

All list endpoints return paginated responses:

```json
{
  "page": 1,
  "per_page": 20,
  "total": 468,
  "total_pages": 24,
  "results": [
    {
      "id": 1,
      "type": "movie",
      "title": "Difret",
      "slug": "difret",
      "overview": "...",
      "poster_url": "https://image.tmdb.org/t/p/w500/...",
      "release_year": 2014,
      "tmdb_rating": 7.2,
      "spoken_languages": ["am"],
      "countries": ["ET"]
    }
  ]
}
```

## JavaScript

```javascript
const res = await fetch('https://api.etmdb.dev/api/v1/movies/popular');
const { results } = await res.json();
results.forEach(m => console.log(`${m.title} (${m.release_year})`));
```

## Python

```python
import httpx

client = httpx.Client(base_url='https://api.etmdb.dev/api/v1')

# Popular movies
movies = client.get('/movies/popular').json()

# Search
results = client.get('/search/multi', params={'q': 'Difret'}).json()

# Trending this week
trending = client.get('/trending/movie/week').json()
```
