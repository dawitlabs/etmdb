## Open Access

All `GET` endpoints are fully public. No API key, no signup, no rate limit for casual use.

```bash
# Works without any header
curl https://api.etmdb.dev/api/v1/movies/popular
```

## Getting an API Key

If you're building an app and want to track usage or unlock higher rate limits, register for a free key:

```bash
curl -X POST https://api.etmdb.dev/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name": "Your Name", "email": "you@example.com"}'
```

**Response:**

```json
{
  "api_key": "etmdb_xxxxxxxxxxxxxxxxxxxx",
  "name": "Your Name",
  "email": "you@example.com",
  "rate_limit": 10000,
  "message": "Save your API key — it will not be shown again."
}
```

Save the key immediately — it is returned only once.

## Using Your Key

Pass it via the `X-Api-Key` header:

```bash
curl -H "X-Api-Key: etmdb_xxxx" https://api.etmdb.dev/api/v1/movies
```

## Rate Limits

| Access | Limit |
|---|---|
| No API key | Shared pool |
| API key | 10,000 requests / day |
